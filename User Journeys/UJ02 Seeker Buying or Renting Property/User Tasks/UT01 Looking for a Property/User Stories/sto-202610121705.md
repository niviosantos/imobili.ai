# User Story: Geospatial Property Visualization on Living Map with Privacy Obfuscation

---

## Summary

- **As a** property seeker browsing available real estate,
- **I want to** visualize matching properties on an interactive Living Map Canvas, viewing either exact location pins or privacy-masked neighborhood centroids depending on tenant privacy policy,
- **So that** I can intuitively assess the geographic distribution of candidate properties across neighborhoods while respecting homeowner privacy.

---

## Scope in/out

- **In Scope:** Interactive map canvas rendering with marker clustering and listing pins per [[con-202609121903]], dynamic privacy masking under `obfuscatedHood: true` per [[req-202609121913]], rendering blurred or shaded neighborhood polygons and centroid indicators for masked listings, rendering precise rooftop pins for unmasked listings, map viewport bounding box (`bbox`) change event synchronization with search listings, and marker click preview cards.
- **Out of Scope:** Overlaying amenity proximity isochrones (handled in [[sto-202610121706]]) and full property media gallery inspection (handled in [[sto-202610121707]]).

---

## Preconditions

1. Living Map Canvas cartographic runtime initialized and active per [[con-202609121903]].
2. Tenant spatial coordinates and neighborhood GeoJSON boundaries populated.
3. Tenant configuration loaded indicating `obfuscatedHood` setting (`true` or `false`) per [[req-202609121913]].

---

## Expected behavior

When search results are returned, candidate properties are projected onto the Living Map Canvas. If the tenant enables `obfuscatedHood: true`, properties are displayed within generalized neighborhood centroid areas without revealing exact street numbers. Clicking or hovering over a marker displays a summary card. Moving or zooming the map updates the active search boundaries.

---

## Acceptance criteria

### Criterion 1: Map Projection and Synchronized Viewport
- **Given** search query results displayed in grid or list view,
- **When** the seeker opens or views the Living Map Canvas,
- **Then** the map must center and adjust zoom to frame all matching candidate property coordinates within the active viewport.

### Criterion 2: Privacy Obfuscation Enforcement (`obfuscatedHood: true`)
- **Given** a tenant instance configured with `obfuscatedHood: true`,
- **When** listings are rendered on the public map canvas,
- **Then** the platform must suppress exact rooftop latitude/longitude coordinates and street numbers, displaying instead a neighborhood centroid pin or shaded GeoJSON polygon perimeter per [[req-202609121913]].

### Criterion 3: Precise Location Rendering (`obfuscatedHood: false`)
- **Given** a tenant instance configured with `obfuscatedHood: false` (or when viewed by authenticated agency personnel),
- **When** listings are rendered on the map canvas,
- **Then** each property must be displayed at its exact street pin location with full street address.

### Criterion 4: Viewport Bounding Box Synchronization
- **Given** an interactive seeker panning or zooming the map canvas,
- **When** the map bounding box stabilizes (`dragend` / `zoomend`),
- **Then** the system must dispatch a spatial boundary query updating the property results list to reflect only properties located within the new visible GeoJSON polygon.

### Criterion 5: Interactive Marker Preview
- **Given** property markers rendered on the map,
- **When** the seeker clicks or hovers over a marker,
- **Then** a floating preview card must appear showing thumbnail, title, price, bedrooms, and a link to view full property details.

## Contracts and data

- **Spatial Query Endpoint:** `POST /api/v1/properties/map-cluster`
- **Example Request with Viewport Bounding Box:**
```json
{
  "bbox": {
    "south_west": { "lat": -23.5700, "lng": -46.7000 },
    "north_east": { "lat": -23.5500, "lng": -46.6800 }
  },
  "zoom": 14
}
```
- **Example Marker Feature Collection (GeoJSON with Obfuscation):**
```json
{
  "type": "FeatureCollection",
  "features": [
    {
      "type": "Feature",
      "geometry": {
        "type": "Point",
        "coordinates": [-46.6912, -23.5614]
      },
      "properties": {
        "id": "prop-sp-042",
        "title": "Apartamento em Pinheiros",
        "price": 850000.00,
        "is_obfuscated": true,
        "neighborhood": "Pinheiros",
        "address_label": "Pinheiros (Endereço exato sob política de privacidade)"
      }
    }
  ]
}
```

---

## Business rules

1. Under `obfuscatedHood: true`, exact street addresses and GPS rooftop coordinates must never be transmitted to the public browser client in map data payloads per [[req-202609121913]].
2. Internal agency personnel (brokers, managers) viewing listings with verified administrative credentials bypass obfuscation per [[con-202609121903]].
3. Spatial queries must strictly observe tenant database boundaries per [[req-202609121910]].

---

## Edge cases and errors

- **High Marker Density:** If viewport contains over 100 listings, the map must automatically cluster points into numerical cluster circles.
- **Listing Outside Boundaries:** If a listing coordinates fall outside known neighborhood geometries, it defaults to the municipal center centroid.
