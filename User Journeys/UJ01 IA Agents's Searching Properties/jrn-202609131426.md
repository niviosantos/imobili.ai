# Journey: Property Search by AI Agents (UJ01)

This journey documents the end-to-end programmatic interaction where an external autonomous AI agent locates the brokerage inventory and executes parameterized searches on behalf of a property seeker.

---

## Persona

- **Primary Persona:** External Autonomous AI Agent (intelligent browser, buyer copilot, or automated search bot operating with client preferences and budget limits).
- **Secondary Persona:** Brokerage A2A Gateway (Imobili.ai Tenant providing machine-readable discovery manifests and query processing).

---

## Goal

Autonomously discover the real estate brokerage's machine interfaces (`agent-card.json` or `/.well-known/mcp`), validate endpoint capabilities, execute parameterized property queries combining hard metadata filters and semantic criteria with dynamic irrelevance floor ranking via A2A JSON-RPC or WebMCP tools, and return verified property listings to the end user.

---

## Stages

1. **Discovery Stage:** The external agent interrogates the agency root domain or well-known endpoints (`/.well-known/agent-card.json` or `/.well-known/mcp`) to retrieve the machine manifest with global CORS headers and service descriptors.
2. **Capability Negotiation Stage:** The agent validates that the tenant supports required query primitives (`search_properties`, vector retrieval, spatial filters, dynamic irrelevance floor).
3. **Query Dispatch Stage:** The agent constructs and dispatches structured search requests with client parameters via A2A JSON-RPC or WebMCP tools (`tools/call`), choosing anonymous Tier 1 access or presenting `X-Agent-Key` for Tier 2.
4. **Result Ingestion Stage:** The agent receives deterministic property payloads with obfuscated neighborhood boundaries (if `obfuscatedHood: true`), parses relevance rankings, and presents candidate properties to the seeker.
