# User Story: Rich Property Detail Inspection and Media Gallery

---

## Summary

- **As a** property seeker evaluating specific real estate opportunities,
- **I want to** select a property from the map or listing feed to inspect its full structural attributes, high-resolution photo gallery, and embedded YouTube video tour,
- **So that** I can assess property condition, layout, finishes, and dimensions thoroughly before committing to a physical visit.

---

## Scope in/out

- **In Scope:** Detailed property view rendering comprehensive attributes (usable area in $m^2$, total area, bedrooms, suites, bathrooms, parking spaces, condo fees, municipal tax IPTU, internal and building amenities), high-resolution photo carousel with lightbox enlargement, responsive YouTube video tour player embedding (`youtube-nocookie.com/embed/{video_id}`) with playback controls, and privacy-compliant address rendering per [[req-202609121913]].
- **Out of Scope:** Guest authentication (handled in [[sto-202610121708]]), bookmarking to preferences (handled in [[sto-202610121709]]), and scheduling on-site visits.

---

## Preconditions

1. Candidate property records published with active metadata, media links, and YouTube video IDs.
2. Tenant web portal detail page routing operational (`/imoveis/{property_id}`).
3. LGPD privacy rules configured per [[req-202609121913]].

---

## Expected behavior

When a seeker clicks a property pin on the Living Map Canvas or a card in search results, the platform navigates to or opens the Property Detail view. The page presents key metrics, an interactive image gallery, an embedded YouTube video tour player, and descriptive architectural highlights, with exact street addresses masked if `obfuscatedHood: true`.

---

## Acceptance criteria

### Criterion 1: Map Marker Selection to Detail View Navigation
- **Given** property markers rendered on the Living Map Canvas or in search results,
- **When** the seeker clicks a property pin or clicks "Ver Detalhes" (View Details),
- **Then** the platform must open the full property inspection view for that specific listing ID without losing prior search filters in browser history.

### Criterion 2: Structural Specification Display
- **Given** the Property Detail view loaded,
- **When** the seeker reviews property features,
- **Then** the platform must render structured property specifications including:
  - Usable and total area ($m^2$)
  - Bedrooms and suites
  - Bathrooms and parking spots (`vagas`)
  - Monthly condominium fee (`condomínio`) and annual IPTU
  - Architectural typology and transaction pricing (sale price or monthly rent)

### Criterion 3: Photo Gallery Carousel and Lightbox
- **Given** a property with uploaded media,
- **When** the seeker interacts with the photo section,
- **Then** the gallery must display responsive images with thumbnail navigation and full-screen lightbox enlargement upon clicking any photo.

### Criterion 4: Embedded YouTube Video Tour
- **Given** a property listing configured with a verified YouTube tour video,
- **When** the seeker navigates to the "Tour em Vídeo" section,
- **Then** the platform must render an embedded responsive YouTube player utilizing `https://www.youtube-nocookie.com/embed/{video_id}` with disabled autoplay, full-screen capability, and standard video playback controls.

### Criterion 5: Privacy-Preserving Address Formatting
- **Given** a tenant with `obfuscatedHood: true`,
- **When** the property detail page is viewed by an unauthenticated seeker,
- **Then** the address must display only the neighborhood and city (e.g., "Pinheiros, São Paulo - SP") with an informative note stating that the exact street address will be revealed upon visit confirmation per [[req-202609121913]].

## Business rules

1. All property data queries must respect tenant isolation per [[req-202609121910]].
2. YouTube embeds must use the privacy-enhanced domain (`youtube-nocookie.com`) to prevent unconsented third-party tracking before seeker interaction.
3. If `obfuscatedHood: true`, exact street name and number must be omitted from all public API payloads per [[req-202609121913]].

---

## Edge cases and errors

- **Missing YouTube Video:** If `youtube_video_id` is null or empty, the video section is gracefully hidden from the UI without blank placeholders.
- **Invalid Property ID:** If requested property does not exist, return HTTP status 404 with a helpful "Imóvel não encontrado ou já desativado" screen.
