# Task: Looking for a Property (UT01)

This task delivers the primary search, spatial filtering, and neighborhood discovery capabilities for human property seekers exploring tenant inventory on the Imobili.ai web platform.

---

## Parent journey

- [[jrn-202610121700]] - Journey: Property Acquisition and Rental for Seekers (UJ02)

---

## Objective

Provide a multi-faceted search experience enabling human seekers to filter properties by geographic attributes (City, neighborhood, cardinal regions), budget bounds, bedroom and suite configurations, and architectural typologies (House, two-story house, apartment, gated community), or natural language lifestyle prompts via dense semantic vector search, evaluating matching listings on the interactive Living Map Canvas with dynamic privacy obfuscation (`obfuscatedHood`) and multi-modal amenity proximity layers (schools, bakeries, grocery stores, pharmacies, gyms, public transit).
