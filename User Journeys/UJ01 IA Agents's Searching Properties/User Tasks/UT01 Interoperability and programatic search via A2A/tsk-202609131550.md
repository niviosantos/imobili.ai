# Task: Interoperability and Programmatic Search via A2A (UT01)

This task implements the technical interoperability capability between external agents and the Imobili.ai inventory service.

---

## Parent journey

- [[jrn-202609131426]] - Journey: Property Search by AI Agents (UJ01)

---

## Objective

Provide standardized auto-discovery endpoints (`/.well-known/agent-card.json` with global CORS headers and HTTP `Link` header) and structured property query execution via JSON-RPC to enable external AI agents to retrieve validated listings.

---

## Preconditions

1. Tenant environment deployed and operational per [[run-202609121908]].
2. Agent manifest published, signed, and serving CORS headers per [[run-202609121909]].
3. Compliance with rate limiting policies defined in [[req-202609121912]].
4. Compliance with tenant isolation rules (no shared pools) defined in [[req-202609121910]].
