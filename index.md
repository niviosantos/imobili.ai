# Root Index: Imobili.ai Ecosystem

Welcome to the **Imobili.ai** knowledge base repository, structured under Google's Open Knowledge Format (OKF) standard with strict separation between declarative knowledge (Concepts) and executable procedural knowledge (Runbooks).
