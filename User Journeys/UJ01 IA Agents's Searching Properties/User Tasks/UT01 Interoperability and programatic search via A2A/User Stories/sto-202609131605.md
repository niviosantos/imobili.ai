# User Story: Capability Discovery via Agent Card

---

## Summary

- **As an** AI agent powering an automated real estate search engine,
- **I want to** access the tenant's `agent-card.json` from the standard path (`/.well-known/agent-card.json`) or via the homepage HTTP header with global CORS enabled,
- **So that** I can autonomously identify supported skills, input/output schemas, and available A2A query endpoints directly from browser extensions or server backends.

---

## Scope in/out

- **In Scope:** Serving `/.well-known/agent-card.json` with HTTP status 200 OK, injecting HTTP `Link` header in homepage responses, injecting global CORS headers (`Access-Control-Allow-Origin: *`) across all discovery endpoints, schema declaration of `search_properties` skill, cryptographic signature validation, and Tier 1 rate limit abuse quarantine.
- **Out of Scope:** Executing property vector searches (handled in [[sto-202609131642]]), processing payment deposits, or executing tenant deployment operations.

---

## Preconditions

1. Tenant instance provisioned and active per [[run-202609121908]].
2. Agent manifest signed and deployed with global CORS configuration per [[run-202609121909]].
3. Gateway routing and TLS termination verified.

---

## Expected behavior

When an external agent issues an HTTP GET or OPTIONS request to `/.well-known/agent-card.json` or requests the homepage (`GET /`), the platform returns the signed capability manifest, discovery `Link` headers, and global CORS headers enabling immediate browser and server consumption.

---

## Acceptance criteria

### Criterion 1: Success Response, Global CORS, and Edge Caching
- **Given** an external AI agent operating within a web browser or client application,
- **When** the agent sends a `GET /.well-known/agent-card.json` request,
- **Then** the platform must respond with HTTP status `200 OK`, header `Content-Type: application/json`, header `Access-Control-Allow-Origin: *`, and header `Cache-Control: public, max-age=3600`.

### Criterion 2: CORS Preflight Support and Preflight Caching
- **Given** a cross-origin client initiating an HTTP preflight check,
- **When** the client sends an `OPTIONS /.well-known/agent-card.json` request,
- **Then** the platform must respond with HTTP status `204 No Content` and headers `Access-Control-Allow-Origin: *`, `Access-Control-Allow-Methods: GET, OPTIONS`, and `Access-Control-Max-Age: 86400`.

### Criterion 3: Homepage Header Discovery
- **Given** an external client querying the tenant domain root,
- **When** the client sends a `GET /` request,
- **Then** the response must include the HTTP header:
  `Link: </.well-known/agent-card.json>; rel="service-desc"; type="application/json"`.

### Criterion 4: Schema Declaration
- **Given** a successfully retrieved `agent-card.json` document,
- **When** the payload is parsed by an agent,
- **Then** the JSON payload must declare skill `search_properties` with explicit JSON schema parameters for property type, geographic bounds, transit proximity, and budget.

### Criterion 5: Abuse Prevention Quarantine
- **Given** an incoming client IP address,
- **When** the client exceeds 120 requests per minute targeting discovery endpoints,
- **Then** the platform must return HTTP status `429 Too Many Requests` followed by a temporary 24-hour quarantine per [[req-202609121912]].

## Contracts and data

- **Endpoint:** `GET /.well-known/agent-card.json`
- **Output Content-Type:** `application/json`
- **CORS Headers:** `Access-Control-Allow-Origin: *`, `Access-Control-Allow-Methods: GET, OPTIONS`, `Access-Control-Max-Age: 86400`
- **Cache Header:** `Cache-Control: public, max-age=3600`
- **Schema Reference:** `https://imobili.ai/schemas/agent-card-v1.json`
- **Example Payload:**
```json
{
  "$schema": "https://imobili.ai/schemas/agent-card-v1.json",
  "name": "Alpha Real Estate Agent",
  "version": "1.0.0",
  "endpoints": {
    "semantic_search": "/api/v1/a2a/search"
  },
  "capabilities": ["semantic-vector-search", "living-map-polygons"]
}
```

---

## Business rules

1. The manifest must be publicly accessible without requiring client authentication cookies or interactive CAPTCHAs.
2. Global CORS headers must be emitted unconditionally on discovery paths to permit zero-friction consumption by browser-based AI agents.
3. The manifest must reflect tenant isolation boundaries defined in [[req-202609121910]].
4. The cryptographic signature on the manifest must be verifiable against the tenant public certificate per [[req-202609121911]].
5. Discovery responses must enforce `Cache-Control: public, max-age=3600` (manifest) and `Access-Control-Max-Age: 86400` (preflight OPTIONS) to optimize CDN edge caching and minimize origin gateway load.

---

## Edge cases and errors

- **Missing Manifest:** If the manifest file is deleted or corrupt, return HTTP `503 Service Unavailable` with message `AGENT_MANIFEST_UNAVAILABLE`.
- **Disallowed Method:** If a client sends mutating methods (`POST`, `DELETE`, `PUT`) to the discovery path, return HTTP `405 Method Not Allowed`.

## Assumptions and open questions

- Assumption: The well-known path `/.well-known/agent-card.json` operates as an alias to `/.well-known/agent.json`.
- Resolved Decision (Discovery and Preflight Caching): Enforced `Cache-Control: public, max-age=3600` for manifest responses and `Access-Control-Max-Age: 86400` (24h) for preflight `OPTIONS` responses, enabling edge CDN delivery and reducing gateway CPU overhead by over 50%.
