# Task: Interoperability and Programmatic Search via WebMCP (UT02)

This task implements the web-native Model Context Protocol (WebMCP) interoperability layer between external AI agents, copilots, search engines, and the Imobili.ai inventory service.

---

## Parent journey

- [[jrn-202609131426]] - Journey: Property Search by AI Agents (UJ01)

---

## Objective

Provide standardized WebMCP auto-discovery endpoints (`/.well-known/mcp` with global CORS and HTTP `Link` headers), HTML/JSON-LD search engine discovery metadata, and structured property query execution via Model Context Protocol tools (`search_properties` over SSE and HTTP POST) to enable external AI agents, copilots, and web search engines (such as Google) to identify service availability and execute parameterized property searches.

---

## Preconditions

1. Tenant environment deployed and operational per [[run-202609121908]].
2. WebMCP runtime architecture and contracts active per [[con-202609121905]] and [[con-202609121907]].
3. Compliance with multi-tenant isolation rules (no shared pools) defined in [[req-202609121910]].
4. Compliance with two-tier rate limiting policies defined in [[req-202609121912]].
5. Compliance with LGPD privacy rules and `obfuscatedHood` address masking per [[req-202609121913]].
