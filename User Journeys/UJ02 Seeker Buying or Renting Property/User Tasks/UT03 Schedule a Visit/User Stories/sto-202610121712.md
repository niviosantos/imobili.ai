# User Story: Direct Broker Engagement via WhatsApp

---

## Summary

- **As a** property seeker browsing a listing or scheduling a visit,
- **I want to** initiate instant contact with a responsible broker via WhatsApp with pre-filled property details,
- **So that** I can ask urgent questions, request custom viewing schedules, and receive immediate assistance directly on my mobile messaging app.

---

## Scope in/out

- **In Scope:** Prominent WhatsApp call-to-action ("Falar com Corretor no WhatsApp") buttons across property detail views, booking dialogs, and favorites lists, generating pre-filled deep links (`https://wa.me/{phone}?text={encoded_text}`) containing property ID, title, and canonical URL, device detection (launching WhatsApp application on mobile or WhatsApp Web on desktop), and registering the lead touchpoint in the brokerage CRM audit log per [[req-202609121911]].
- **Out of Scope:** Automated AI chatbot conversations inside WhatsApp (handled in separate conversational bot integrations) and negotiating binding contract terms without prior registration.

---

## Preconditions

1. Responsible broker or agency WhatsApp business phone number configured.
2. Property record active with valid canonical URL.
3. Seeker browser equipped with WhatsApp client or web capability.

---

## Expected behavior

When a seeker clicks "Falar com Corretor no WhatsApp" on a property page or during scheduling, the platform generates a deep link pre-populated with a polite Brazilian Portuguese message referencing the property ID and title, logs the contact intent in the tenant CRM, and opens WhatsApp on the seeker's device in a new browser tab or application window.

---

## Acceptance criteria

### Criterion 1: Contextual WhatsApp Button Visibility
- **Given** a property seeker viewing a listing on the detail page or visit scheduling dialog,
- **When** the seeker inspects broker contact options,
- **Then** the platform must render a prominent green WhatsApp CTA button with official brand iconography and label "Conversar no WhatsApp".

### Criterion 2: Pre-Formatted Property Message Deep Link
- **Given** a seeker clicking the WhatsApp CTA for property `prop-sp-042`,
- **When** the link is generated,
- **Then** the target URL must conform to `https://wa.me/{broker_phone}?text={encoded_message}` where `{encoded_message}` contains:
  - Property reference code (e.g., `REF #prop-sp-042`)
  - Property title (e.g., `Apartamento em Pinheiros`)
  - Seeker intent text: "Olá! Vi este imóvel no portal e gostaria de tirar dúvidas ou agendar uma visita."
  - Property canonical link: `https://alpha.imobili.ai/imoveis/prop-sp-042`

### Criterion 3: Responsive Multi-Device Launch
- **Given** a seeker clicking the WhatsApp CTA,
- **When** accessed on a mobile phone (iOS / Android),
- **Then** the platform must trigger the native WhatsApp application; when accessed on a desktop workstation, it must navigate to `web.whatsapp.com` in a new tab (`target="_blank" rel="noopener noreferrer"`).

### Criterion 4: Lead Attribution and CRM Logging
- **Given** a seeker clicking the WhatsApp link,
- **When** the click event fires,
- **Then** the platform must send an asynchronous tracking event to `/api/v1/leads/whatsapp-click`, logging property ID, broker ID, timestamp, and anonymous or authenticated seeker ID into the tenant's immutable audit log per [[req-202609121911]].

### Criterion 5: Obfuscated Address Invariant
- **Given** a property with `obfuscatedHood: true`,
- **When** the pre-formatted WhatsApp message is generated,
- **Then** the text message must reference only the neighborhood name and property ID, never including the masked street number in the outbound message text per [[req-202609121913]].

## Business rules

1. All outbound WhatsApp contact leads must be recorded inside the isolated tenant collection per [[req-202609121910]].
2. Lead tracking records must include cryptographic sequencing per [[req-202609121911]].
3. Outbound message text must strictly honor neighborhood privacy masking under `obfuscatedHood: true` per [[req-202609121913]].

---

## Edge cases and errors

- **Missing Broker Phone:** If the listing has no designated broker phone, fall back to the central agency reception WhatsApp number.
- **Ad Blocker / Popup Blocker:** If opening the new tab is blocked by browser security, render a prominent fallback alert: "Clique aqui para abrir o WhatsApp diretamente".
