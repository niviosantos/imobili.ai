# Structural Failures in Traditional PropTech

This note records the five fundamental market failures identified in the traditional real estate ecosystem, serving as the foundational rationale for Imobili.ai's architectural design.

---

## Definition

Traditional PropTech refers to first- and second-generation real estate advertising portals designed around rigid SQL filter dropdowns, human eye-tracking user interfaces, closed proprietary databases, and static map markers. These architectures create artificial listing invisibility, high onboarding friction, and total incompatibility with autonomous agentic computing.

---

## Rationale

Autonomous AI agents evaluate listings via semantic intent, structured schemas, and geometric computations. Legacy platforms fail because they were engineered to force human visitors through visual ad funnels, deliberately obstructing programmatic API consumption through CAPTCHAs and obfuscated markup.

---

## Rules and constraints

1. **Anti-Invisibility Rule:** Systems must not rely on exact lexical substring matches that hide semantically equivalent properties.
2. **Machine-Readability Mandate:** All property endpoints must support structured, machine-parsable representations alongside human presentations.
3. **Dynamic Cartography Constraint:** Map interfaces must provide computed geometric surfaces (isochrones and polygons) rather than passive, disconnected coordinate pins.
4. **Zero Forced Intermediation:** Infrastructure deployment must not require closed, multi-week commercial sales cycles or proprietary lock-in.

---

## Examples

1. **Lexical Retrieval Failure:** A seeker queries for *"top-floor apartment with morning sunlight near a quiet bakery"*; legacy exact-match search returns zero results because the listing description says *"penthouse east-facing facing artisan cafe"*.
2. **Agent Scraping Breakdown:** An autonomous copilot attempts to extract price and bedroom counts from a legacy portal; a layout modification or CAPTCHA triggers runtime failure and token waste.
3. **Static Distance Delusion:** A portal displays a property as *"500 meters from subway"*, but pedestrian access requires crossing an unpassable highway with no footbridge; static distance calculations misrepresent true transit feasibility.
